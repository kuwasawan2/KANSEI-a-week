# 週イチ（仮）— 毎週1作の個人制作投稿サイト モックアップ

`index.html` を開くだけで **お試しモード** で動きます（データはブラウザの中だけ。再読み込みで消えます）。
Supabase につなぐと、実際に投稿・保存・コメントができるようになります。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | サイト本体（1ファイル完結） |
| `supabase-setup.sql` | Supabase 側の台帳・倉庫・鍵の設定をまとめて作る指示書 |

## Supabase につなぐ手順（初回だけ・15分ほど）

1. **登録**：supabase.com で GitHub アカウントかメールで登録（カード不要）
2. **プロジェクトを作る**：「New project」→ 名前を入力、Region は **Northeast Asia (Tokyo)**、データベースのパスワードを決めて作成
3. **台帳と倉庫を作る**：左メニュー「SQL Editor」→ `supabase-setup.sql` の中身をまるごと貼って「Run」
4. **メール確認をオフにする**：「Authentication」→「Sign In / Providers」→「Email」で **Confirm email をオフ** にして保存（メールが一切送られなくなります）
5. **合言葉をコピー**：「Project Settings」→「API Keys」で
   - Project URL（`https://xxxx.supabase.co`）
   - **anon key** または **publishable key**
   を `index.html` 冒頭の `SUPABASE_URL` と `SUPABASE_KEY` に貼る
   ⚠️ **secret key / service_role key は絶対に貼らない・GitHubに上げない**
6. **公開**：GitHub のリポジトリに置いて、Settings → Pages で公開


## このモックアップでできること

- メールアドレスとパスワードで新規登録・ログイン → 表示名を決める
- 今週の締切カウントダウン（日曜23:59 日本時間）
- 1人1週1作の提出（画像は自動で長辺1600pxに縮小）＋振り返り3項目・見てほしい点
- 今週の作品一覧／週ごとのアーカイブ
- 作品の詳細とコメント
- マイページ：連続週数・作品数・休み数、週ごとの提出マス
- 今週中なら自分の作品を取り下げて出し直し

## 守りの設定（supabase-setup.sql に入っているもの）

- 見るのは誰でもOK、書くのはログインした人だけ
- 投稿者と週はサーバー側で自動で決まる（過去の週にこっそり出せない）
- 同じ人が同じ週に2作出せない
- 消せるのは自分の作品（今週分のみ）と自分のコメントだけ
- 画像は自分のフォルダにだけ置ける、1枚2MBまで

## 注意

- 無料プランは1週間使われないと一時停止します（管理画面から再開でき、データは消えません）。
- `SITE_START` を WEEK 01 の月曜日に合わせて変更してください。
